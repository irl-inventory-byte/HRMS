Every account's view and edit rights are decided by the role set here — Admin sees and edits everything, HR only sees Dashboard + Interviews + Applications, Manager only sees Dashboard + Leave, Interviewer only sees Dashboard + Walk-in + Interviews, Employee only sees the Dashboard, and Candidate (auto-assigned to anyone who signs up with a @gmail.com address) only sees the Application Form. Changing a role here updates Postgres directly — Row Level Security enforces it even if someone tampers with the browser.
